== Назначение ==

Блокирует отправку писем при совпадении нескольких признаков рекламы. При выключенной блокировке можно помечать копию заявки. Проверка выполняется на сайте.

== Настройки ==

Откройте «Настройки → Спам Email ZA» и включите блокировку. Для пометок выключите блокировку и укажите адрес, который уже настроен для получения копий. Одно правило на строку. Разделитель признаков — `|`. Варианты одного признака разделяйте ` / `, с пробелами с обеих сторон. Совпасть должны все группы.

Часть русскоязычных фраз адаптирована из TGtrigger (Alexander Zabrodin, MIT). Источник — https://github.com/A1exZabr/tgtrigger/blob/main/backend/ai_scorer.py. Лицензия находится в LICENSE-tgtrigger.txt.

== Подключение формы ==

Перед обычным вызовом `wp_mail()` передайте в `apply_filters('seza_deliver_inquiry', null, $recipients, $subject, $body, $headers, $text)` адреса и параметры почты, а в последнем аргументе только текст, который ввёл посетитель. Если результат равен `null`, вызовите штатный `wp_mail()`. Значение `bool` — результат уже обработанной отправки. После успешной отправки используйте существующий учёт заявки.

На PHP-сайтах класс `SpamEmailZA\Rules` можно подключить отдельно. Метод `match` возвращает названия совпавших правил. Обработчик сайта сам выбирает получателей и отправляет письмо.

== Выпуск обновлений ==

Проверьте версию в PHP, readme.txt и update.json и отправьте тег `vX.Y.Z` в GitHub. Workflow публикует версионный ZIP и update.json в Releases. WordPress получает их по HTTPS во время штатной проверки. В списке плагинов доступно управление автообновлениями.
