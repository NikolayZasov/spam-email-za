# Как составлены стартовые правила

Набор написан для русскоязычных форм заявки. В него входят рекламные услуги, оплата за лиды, продвижение через Reels и приглашения рекламных агентств в мессенджер. Примеры в тестах обезличены. В правилах каждый отдельный признак проверяется только вместе с остальными признаками той же строки.

- Apache SpamAssassin использует комбинации эвристик и оценку нескольких сигналов. Этот принцип можно применять к содержимому формы. Его правила рассчитаны на почту, в том числе на SMTP-заголовки и транспорт, поэтому списки не переносились. [Репозиторий Apache](https://github.com/apache/spamassassin/blob/trunk/README)
- В TelegramSpamGuardBot есть открытый для просмотра словарь русских фраз. В просмотренном GitHub-репозитории нет заявленной лицензии для подстановки словаря в коммерческий пакет. [TelegramSpamGuardBot](https://github.com/TakuyaYagam1/TelegramSpamGuardBot)
- RuSpam и TeleSpam содержат размеченные сообщения. На обеих карточках указана некоммерческая лицензия CC BY-NC 4.0. [RuSpam](https://huggingface.co/datasets/ruSpamModels/russian-spam-detection) · [TeleSpam](https://huggingface.co/datasets/AugustLight/telegram_spam_ru)

Стартовый набор проверен на признаках из известного рекламного предложения и примерах обычных заявок. Репрезентативной оценки точности пока нет.
